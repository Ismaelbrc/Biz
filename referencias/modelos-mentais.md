# Modelos Mentais e Templates: Codie Sanchez → Chris Koerner

Referência consolidada dos frameworks, templates e modelos mentais dos principais operadores do movimento de boring business + aquisição + automação.

---

## 1. Codie Sanchez — Contrarian Thinking

**Tese central:** A maioria das pessoas ignora negócios chatos porque quer ser interessante. Isso cria uma ineficiência enorme de mercado. O dinheiro está onde a atenção não está.

### Modelo Mental: "Zombie Businesses"
Negócios que caminham sozinhos mas não têm dono comprometido ou sucessor. Características:
- Dono com 55+ anos sem plano de saída
- Faturamento estável há anos, sem crescimento
- Nenhuma presença digital
- Clientes fiéis que ninguém prospectou ativamente

> São os melhores ativos para comprar. Já provaram que funcionam. O comprador só precisa não estragar.

### Template: Filtro Rápido de Aquisição (5 perguntas)
1. O negócio gera caixa positivo há pelo menos 3 anos?
2. O dono precisa estar presente para funcionar? (se sim: quanto tempo para me tornar dispensável?)
3. Qual o motivo real da venda? (aposentadoria ≠ fuga do problema)
4. A receita está concentrada em menos de 3 clientes? (se sim: risco alto)
5. Consigo comprar por menos de 3x o lucro anual com parte financiada pelo vendedor?

### Template: Estrutura de Deal Preferida
```
Preço total:        3x SDE (Seller's Discretionary Earnings)
Entrada à vista:    30-40% (idealmente via SBA loan)
Seller financing:   60-70% em 24-36 meses
Taxa de juros:      5-7% a.a. sobre o saldo
Cláusula:           Caução do próprio negócio como garantia
```

### Os 3 Alavancas de Qualquer Negócio
1. **Receita** — mais clientes, maior ticket, maior frequência
2. **Despesa** — cortar o que não gera receita, automatizar o que é repetitivo
3. **Dívida** — estruturar para crescer, não para sobreviver

## 2. Mark Cuban

**Tese central:** Vendas resolve tudo. Conhecimento profundo do seu negócio é a única vantagem sustentável. Esforço é democratizado — qualquer um pode fazer, poucos fazem.

### Modelo Mental: "Effort Advantage"
Na era da informação, a informação é commodity. O que diferencia é o que você faz com ela. Regra:

> Se você trabalha 8h e o concorrente trabalha 8h, estão empatados. Se você trabalha 16h, você dobrou a vantagem sem gastar nada.

Aplicação prática: no início de qualquer negócio, o dono deve ser o melhor vendedor, o melhor técnico e o melhor atendente. Não por perfeccionismo — para entender onde o negócio quebra.

### Template: Regras de Mark Cuban para Novos Negócios
1. Não abra negócio que você não usaria como cliente
2. Leia cada contrato que você assina — cada palavra
3. Nunca confie em projeções de receita; confie em receita real
4. Venda antes de construir — prove a demanda com dinheiro na mão
5. O primeiro empregado resolve seu maior problema operacional, não o segundo
6. "Sales cure all" — quando em dúvida, vá vender

### Modelo Mental: "Don't Take No From Someone Who Can't Say Yes"
Muito tempo é perdido tentando convencer pessoas que não têm autoridade para decidir. Identifique quem pode dizer sim e vá direto.

## 3. Nick Huber — Sweaty Startup

**Tese central:** Negócios que exigem suor físico e presença local são naturalmente defensáveis. A tecnologia não consegue substituir um caminhão de mudança ou uma unidade de self-storage.

### Modelo Mental: "Sweaty Business Criteria"
Um negócio vale entrar se:
- [ ] Tem barreira de entrada por esforço, não por patente ou segredo
- [ ] O cliente está no raio de 30km (competição local, não nacional)
- [ ] É difícil de escalar virtualmente (exige ativos físicos ou presença)
- [ ] Tem demanda recorrente e previsível
- [ ] O incumbente local opera de forma amadora (sem sistema, sem presença digital)

### Template: Pilha de Criação de Riqueza do Huber
```
Passo 1: Abrir ou comprar um serviço local gerando R$15-30k/mês líquido
Passo 2: Automatizar operação, contratar gerente, tirar o dono do dia a dia
Passo 3: Usar o fluxo de caixa para comprar imóvel comercial (o próprio ponto)
Passo 4: Usar imóvel como colateral para próxima aquisição
Passo 5: Repetir — cada negócio financia o próximo
```

### Modelo Mental: "Hire Slow, Fire Fast"
Processo de contratação do Huber:
1. Escreva o processo antes de contratar (quem faz o quê, passo a passo)
2. Contrate para o processo, não para a intuição
3. 90 dias de avaliação com critérios objetivos definidos no dia 1
4. Demissão rápida protege a cultura — tolerar performance baixa é injusto com quem performa bem

## 4. Alex Hormozi — Gym Launch / Acquisition.com

**Tese central:** O produto é secundário. A oferta é primária. Qualquer negócio pode escalar se a oferta for boa o suficiente. E unit economics sólidos antes de qualquer escala.

### Template: A Equação de Valor
```
         Resultado Desejado × Probabilidade Percebida de Sucesso
Valor = ────────────────────────────────────────────────────────
                   Tempo de Espera × Esforço/Sacrifício
```

Para aumentar o valor percebido:
- Aumentar a especificidade do resultado prometido
- Reduzir o tempo para o primeiro resultado
- Remover fricção e esforço do cliente
- Adicionar garantias que reduzem risco percebido

### Template: Grand Slam Offer (Oferta Irresistível)
```
Produto core
+ Bônus 1 (resolve objeção principal)
+ Bônus 2 (resolve objeção secundária)
+ Garantia (inverte o risco)
+ Escassez/urgência real (não falsa)
= Oferta que faz o cliente se sentir burro de recusar
```

### Template: Os 4 Canais de Aquisição de Clientes
Em ordem de custo e velocidade:
1. **Warm outreach** — lista de contatos existentes; custo zero, velocidade alta
2. **Conteúdo orgânico** — lento para começar, composto ao longo do tempo
3. **Cold outreach** — escalonável, custo baixo, requer sistema
4. **Paid ads** — rápido, caro, requer oferta já validada nos 3 anteriores

> Erro comum: começar pelo 4 sem validar os anteriores.

### Modelo Mental: Unit Economics Primeiro
Antes de qualquer escala, saiba de cor:
- **CAC** (Custo de Aquisição de Cliente)
- **LTV** (Valor do Cliente no Tempo)
- **LTV:CAC ratio** — saudável acima de 3:1
- **Payback period** — quanto tempo para recuperar o CAC

Se LTV:CAC < 3:1, escalar é queimar dinheiro mais rápido.

### Template: A Regra dos 100
Para qualquer novo negócio, por 100 dias consecutivos:
- 100 ações de alcance por dia (ligações, DMs, e-mails, conteúdos)
- Sem exceção, sem dia de folga
- Registrar resultados e iterar na abordagem

> Quem faz 100 dias de 100 ações não precisa de sorte.

## 5. Brent Beshore — Permanent Equity

**Tese central:** O private equity tradicional destrói valor ao otimizar para o exit. Negócios familiares saudáveis prosperam quando alguém compra para ficar para sempre.

### Modelo Mental: "Permanent Capital"
A maioria dos compradores de negócio quer vender em 5-7 anos. Isso cria pressão por crescimento artificial, corte de custos destrutivos e destruição de cultura. Beshore faz o oposto:

> Comprar uma vez. Operar bem. Nunca vender. Usar o fluxo de caixa para comprar o próximo.

Consequência: ele pode pagar preços menores porque oferece algo raro — um dono que nunca vai forçar uma venda.

### Template: Perfil do Negócio Ideal (Permanent Equity)
- EBITDA entre US$1M e US$10M
- Setor "essencial" — sobrevive em recessão
- Sem cliente representando mais de 20% da receita
- Gestão existente quer ficar
- Localizado em mercado secundário (menos competição por aquisição)
- Operando há mais de 10 anos

### Modelo Mental: "Complexity Tax"
Cada camada de complexidade adicionada a um negócio cobra um imposto invisível:
- Tempo de gestão
- Erros operacionais
- Dificuldade de contratação
- Margem comprimida

> A pergunta não é "podemos adicionar isso?" — é "o que este projeto vai custar em complexidade?"

## 6. Walker Deibel — Buy Then Build

**Tese central:** A taxa de sucesso de abrir do zero é 10%. A taxa de sucesso de comprar um negócio já funcionando é 80%+. Por que os empreendedores ainda escolhem o caminho mais difícil?

### Template: O Caminho do Acquisition Entrepreneur
```
Fase 1 — PREPARAÇÃO (3-6 meses)
  → Definir critérios de busca (setor, geografia, tamanho, modelo)
  → Construir time: advogado M&A, contador, advisor de setor
  → Organizar capital: próprio + SBA + investidores

Fase 2 — BUSCA (6-18 meses)
  → Deal flow ativo: corretores, prospecção direta, rede
  → Meta: avaliar 100 negócios para fazer 1 oferta
  → LOI em no máximo 3 negócios simultaneamente

Fase 3 — AQUISIÇÃO (3-6 meses)
  → Due diligence: financeiro, legal, operacional, mercado
  → Negociação de termos (preço é menos importante que estrutura)
  → Fechamento e transição com o dono anterior

Fase 4 — OPERAÇÃO (12-24 meses)
  → 100 dias: observar, documentar, não mudar
  → Identificar o maior problema e resolvê-lo
  → Construir processos para tirar o dono do dia a dia

Fase 5 — ESCALA
  → Crescimento orgânico ou bolt-on acquisitions
  → Exit ou reinvestimento
```

### Template: Valuation por SDE
```
SDE = Lucro líquido
    + Salário do dono (pró-labore)
    + Benefícios pessoais no CNPJ
    + Depreciação e amortização
    + Despesas não recorrentes
    - Custo real de gestão substituta

Múltiplo típico: 2x a 4x SDE dependendo do setor e risco
```

### Os 7 Erros Fatais na Aquisição
1. Pagar demais (sem normalizar o SDE)
2. Subcapitalizar (sem reserva para os primeiros 12 meses)
3. Setor errado (mercado em declínio estrutural)
4. Localização errada (mercado que não comporta o negócio)
5. Fit ruim (dono não consegue operar o que comprou)
6. Pular due diligence (o passivo oculto aparece depois)
7. Transição malfeita (dono sai antes de transferir o conhecimento)

## 7. Dan Pena — QLA (Quantum Leap Advantage)

**Tese central:** A maioria das pessoas subestima radicalmente o que pode alcançar. O único limite real é a ambição mal calibrada e a falta de execução brutal.

### Template: A Metodologia QLA
```
Passo 1: Definir meta absurda (não 10% a mais — 10x)
Passo 2: Encontrar mentor que já fez (não coach, não teórico — operador)
Passo 3: Adquirir empresa-plataforma com OPM (Other People's Money)
Passo 4: Usar a plataforma para bolt-on acquisitions
Passo 5: Escalar via M&A, não via crescimento orgânico lento
```

### Modelo Mental: OPM — Other People's Money
> Você não precisa de dinheiro para comprar um negócio. Você precisa de credibilidade e de um deal bom o suficiente para que outros coloquem o dinheiro.

Fontes de OPM para aquisição:
- Seller financing (o próprio vendedor financia)
- Bancos (colateral é o negócio comprado)
- Investidores (equity em troca de capital)
- Parceiros estratégicos (acesso a mercado em troca de participação)

### Modelo Mental: "Dreamstealers"
As pessoas que mais te desencorajam são as que mais te amam — porque têm medo de te ver falhar (ou de te ver ter sucesso e mudar). Identifique-as. Não as ouça em decisões de negócio.

## 8. Patrick Bet-David — PHP Agency / Valuetainment

**Tese central:** Negócios crescem quando o dono entende o que motiva cada stakeholder — cliente, funcionário, sócio, concorrente — e age de acordo.

### Template: Mapeie Seus 5 Próximos Movimentos
Antes de qualquer decisão de negócio, responda:
1. O que quero no final? (o destino)
2. O que precisa acontecer para chegar lá? (movimento 5)
3. O que precisa acontecer antes disso? (movimento 4)
4. …e antes disso? (movimentos 3, 2, 1)
5. O que faço amanhã de manhã? (movimento 1 — o único que importa hoje)

### Modelo Mental: O Triângulo da Motivação
Todo ser humano age por uma combinação de:
- **Dinheiro** — segurança, liberdade, status financeiro
- **Poder** — controle, influência, autonomia
- **Status** — reconhecimento, pertencimento, legado

Para vender, contratar, negociar: descubra qual dos três domina a pessoa à sua frente.

### Template: Visão 1/3/5/10 Anos
```
10 anos: Onde quero estar? (visão ampla, qualitativa)
5 anos:  Qual o negócio que me leva lá? (tamanho, setor, posição)
3 anos:  Qual é a principal métrica que precisa mudar? (receita, equipe, produto)
1 ano:   Quais 3 projetos definem o ano? (foco absoluto)
```

## 9. Roland Frasier — EPIC

**Tese central:** Você não precisa de dinheiro para comprar negócios. Você precisa de criatividade estrutural e conhecimento de deal flow.

### Template: 10 Formas de Comprar Sem Capital Próprio
1. **Seller financing** — vendedor financia a si mesmo
2. **Earn-out** — parte do preço atrelada a performance futura
3. **Revenue-based financing** — investidor recebe % da receita até recuperar o capital
4. **Equity for services** — você entrega valor (gestão, rede, expertise) em troca de participação
5. **Assumption of debt** — assume dívida existente como parte do preço
6. **License agreement** — licencia a operação antes de comprar
7. **Joint venture** — parceria sem transferência formal de propriedade
8. **Consulting-to-acquire** — entra como consultor, negocia aquisição ao longo do projeto
9. **Asset purchase** — compra ativos específicos, não o CNPJ (evita passivo)
10. **Distressed acquisition** — compra em crise por fração do valor

### Modelo Mental: "Preço, Termos, Condições — Escolha Dois"
Em qualquer negociação de aquisição, você pode otimizar dois dos três:
- **Preço baixo** + **termos favoráveis** = condições apertadas (risco de passivo)
- **Preço baixo** + **condições limpas** = termos ruins (pagamento rápido à vista)
- **Termos favoráveis** + **condições limpas** = preço mais alto

> Decida o que é mais importante para você antes de sentar na mesa.

### Template: Os 3 Alavancas de Qualquer Negócio Digital/Serviço
```
Tráfego (ou leads) × Conversão × Ticket Médio = Receita

Para dobrar receita, você precisa mover apenas um desses 3 em 26%,
ou dois deles em ~12% cada.
```

## 10. Chris Koerner — The Boring Marketer

**Tese central:** Negócios locais chatos + IA aplicada = arbitragem que ninguém está fazendo ainda. O dono médio de lava-rápido usa WhatsApp e planilha. Quem chegar com sistema + automação + SEO já venceu.

### Modelo Mental: "AI Wrapper Play"
Pegar um serviço que uma pessoa faz manualmente hoje e inserir IA no meio:
```
Antes: cliente liga → atendente anota → envia orçamento por WhatsApp → follow-up manual
Depois: cliente envia mensagem → IA qualifica → sistema envia orçamento → automação faz follow-up
Resultado: mesma entrega, 80% menos custo de atendimento, 3x mais leads convertidos
```

### Template: Auditoria de Negócio Local (5 perguntas do Koerner)
1. Quantos leads entram por semana e qual o % convertido? (se o dono não sabe: oportunidade)
2. Existe processo documentado de follow-up de orçamento? (quase nunca existe)
3. Qual o tempo de resposta ao primeiro contato do lead? (benchmark: <5 minutos dobra conversão)
4. O negócio aparece no Google Maps para as 3 palavras-chave principais? (SEO local = moat)
5. Quantas avaliações no Google? (abaixo de 50: oportunidade enorme)

### Template: Stack de Automação para Negócio Local (custo <R$1.000/mês)
```
CRM:              HubSpot Free ou Kommo
Agendamento:      Calendly ou TidyCal
WhatsApp API:     Z-API ou Evolution API + n8n
Cobrança:         Asaas (boleto, cartão, Pix automatizados)
Avaliações:       NiceJob ou Birdeye (pede review automaticamente)
Relatório:        Google Looker Studio conectado ao CRM
IA no atendimento: OpenAI API via n8n (responde FAQ, qualifica lead)
```

### Modelo Mental: "Local SEO como Moat"
Um negócio local que aparece em primeiro lugar no Google Maps para seus serviços principais tem uma vantagem quase impossível de desalojar em curto prazo:
- Leva 12-24 meses para construir
- Depende de avaliações genuínas (não compráveis)
- O concorrente não consegue "comprar" a posição

> Invista em SEO local antes de qualquer outra forma de marketing. É o único que compõe.

## Como Usar Este Material

Ao analisar um negócio, pergunte:
- **Codie:** Isso é um zombie business que posso comprar barato?
- **Cuban:** Sei mais sobre este negócio do que qualquer concorrente?
- **Huber:** A operação exige esforço que afasta concorrência preguiçosa?
- **Hormozi:** A oferta é boa o suficiente para o mercado não resistir?
- **Beshore:** Eu ficaria feliz de ter este ativo para sempre?
- **Walker:** O histórico de caixa justifica o preço pedido?
- **Koerner:** Onde posso inserir IA e automação para dobrar a margem?
