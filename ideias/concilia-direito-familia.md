# Concilia — App de Direito de Família

Plataforma completa para o ciclo jurídico familiar:
divórcio, pensão alimentícia, guarda e co-parentalidade.

---

## Por Que Um Produto Só Faz Sentido

Nos EUA, são apps separados: Hello Divorce para divórcio,
SupportPay para pensão, OurFamilyWizard para co-parentalidade.

No Brasil, é a mesma pessoa vivendo a mesma jornada em sequência:

```
JORNADA REAL DO USUÁRIO

Mês 1-3:   Decide se divorciar → precisa entender os direitos
Mês 2-4:   Negocia os termos (guarda, pensão, bens)
Mês 3-5:   Executa o divórcio (cartório ou juiz)
Mês 4+:    Controla o pagamento da pensão todo mês
Mês 4+:    Coordena a agenda da guarda compartilhada
Mês 4+:    Documenta quando o acordo não é cumprido
Anos +:    Revisão da pensão conforme a criança cresce
```

Um app que acompanha essa jornada inteira tem:
- LTV 10x maior que um produto pontual
- NPS altíssimo (resolve dor emocional + jurídica)
- Defensabilidade: o histórico de comunicação e pagamento
  fica na plataforma — o usuário não consegue sair

## Os Módulos

### Módulo 1 — Divórcio Assistido

**Triagem inicial (gratuita):**
```
5 perguntas que determinam o caminho:
  1. Vocês chegaram a um acordo? (consensual / litigioso)
  2. Têm filhos menores de 18 anos? (cartório não aceita se tiver)
  3. Têm bens a partilhar? (imóvel, veículo, investimentos)
  4. Há violência doméstica no histórico? (protocolo especial)
  5. Há dívidas em comum? (complicador relevante)

Resultado imediato:
  ✅ Elegível para divórcio extrajudicial (cartório) → Módulo A
  ⚠️ Precisa de advogado → Referral para rede de advogados parceiros
  🚨 Violência doméstica → Protocolo especial + CRAM + Defensoria
```

**Caminho A — Extrajudicial (cartório):**
```
Sem filhos menores + consensual = pode fazer no cartório
Desde 2007. Menos de 5% dos divorsos usam essa via.
Por quê? Ninguém explica como fazer.

Plataforma faz:
  → Gera minuta da escritura de divórcio
  → Calcula e orienta sobre ITBI (se há imóvel)
  → Lista todos os documentos necessários para o cartório
  → Agenda o cartório via e-Notariado
  → Monitora até a escritura ser lavrada
  → Custo do cartório: R$800-2.500 (vai para o cartório)
  → Custo da plataforma: R$499 fixo

Prazo real com a plataforma: 15-30 dias
Prazo sem a plataforma: 3-6 meses (por não saber o processo)
```

**Caminho B — Judicial (com filhos ou litigioso):**
```
Plataforma não substitui o advogado — mas prepara o terreno:
  → Gera resumo da situação para o advogado
    (economiza 2h de reunião inicial)
  → Calcula estimativa de pensão pelo critério do tribunal local
  → Orienta sobre o que esperar do processo
  → Conecta com advogado de família parceiro
    (triagem feita → advogado começa mais rápido → honorário menor)
  → Receita: 25% do honorário do advogado parceiro
```

**Acordo de Divórcio — o documento central:**
```
Seja extrajudicial ou judicial, o acordo precisa definir:
  → Guarda (unilateral ou compartilhada)
  → Regime de visitas (dias, horários, feriados, férias)
  → Pensão alimentícia (valor, forma de pagamento, reajuste)
  → Partilha de bens (quem fica com o quê)
  → Dívidas em comum (quem assume o quê)

Plataforma gera o documento com linguagem jurídica correta,
customizado para o estado (GO, DF) e situação específica.
Advogado parceiro revisa e assina digitalmente.
```

### Módulo 2 — Pensão Alimentícia

**O problema real:**
70% dos acordos judiciais de pensão alimentícia não são cumpridos
integralmente. O processo de cobrar é lento, humilhante e caro.
A maioria das mães simplesmente absorve o prejuízo.

**Rastreamento de pagamentos:**
```
Configuração:
  → Valor acordado: R$800/mês
  → Dia de vencimento: todo dia 5
  → Conta bancária (ou PIX) do pagador

Todo mês, automaticamente:
  Dia 1: lembrete para o pagador via WhatsApp
  Dia 5: verifica se houve depósito (Open Finance ou confirmação manual)
  Dia 6: não pagou → notificação formal automática
  Dia 10: ainda não pagou → gera carta de cobrança com valor + juros legais
  Dia 15: ainda não pagou → opção de acionar execução judicial
```

**Documentação auditável:**
```
Todo pagamento registrado:
  → Data, valor, forma de pagamento
  → Screenshot do comprovante (opcional)
  → Saldo devedor acumulado se houver atrasos

Histórico completo gera relatório para uso em:
  → Execução de alimentos (prisão civil)
  → Revisão de pensão
  → Processo de guarda (prova de abandono financeiro)
```

**Execução de alimentos — o diferencial:**
```
Devedor de alimentos pode ser preso no Brasil (prisão civil).
Pouquíssimas mães sabem disso ou sabem como acionar.

Plataforma:
  → 3 meses de atraso documentados → gera petição de execução
  → Conecta com advogado parceiro para protocolo
  → Custo: R$299 fixo (vs. R$2.000+ com advogado tradicional)
  → Resultado: pagar ou ir preso — taxa de pagamento sobe para 85%
```

**Revisão de pensão:**
```
Pensão deve ser reajustada anualmente (INPC no mínimo).
A cada 2-3 anos pode ser necessária revisão por mudança de renda.

Plataforma:
  → Aplica reajuste anual automaticamente e notifica ambas as partes
  → Simula: "Com a renda declarada do pagador, a pensão deveria ser R$X"
  → Se diferença > 20%: orienta sobre pedido de revisão judicial
```

### Módulo 3 — Co-parentalidade

**O produto mais inovador e com maior LTV.**

Após o divórcio, se há filhos, os ex-cônjuges vão se relacionar
por 15-20 anos. Esse relacionamento precisa ser gerenciado —
especialmente quando a comunicação direta é conflituosa.

**Calendário compartilhado de guarda:**
```
Configura o regime de guarda uma vez:
  → Semanas alternadas
  → Dias fixos da semana
  → Regime personalizado

Gera automaticamente:
  → Calendário do ano inteiro com dias de cada pai
  → Feriados nacionais e regionais (GO/DF) distribuídos conforme acordo
  → Férias escolares (50%/50% ou conforme o acordo)
  → Aniversário da criança (alternado ou junto)

Ambos os pais veem o mesmo calendário em tempo real.
Solicitação de troca: um propõe, outro aprova ou recusa.
Toda troca fica registrada (prova de boa-fé ou má-fé).
```

**Comunicação auditável:**
```
Canal de mensagens dentro do app:
  → Toda mensagem tem timestamp imutável
  → Não pode ser deletada por nenhuma das partes
  → Pode ser exportada como prova para o juiz

Por que isso importa:
  → "Ele disse que eu nunca aviso quando vou buscar" → histórico prova o contrário
  → "Ela impede as visitas" → há 12 registros de tentativa negada documentados
  → Juízes em GO e DF já aceitam histórico de apps como prova em audiência

Terceiro com acesso de leitura:
  → Advogado, psicólogo, mediador pode ser adicionado como observador
  → Não participa — só lê
  → Aumenta o comportamento adequado de ambas as partes
```

**Controle de gastos extraordinários:**
```
Despesas ordinárias: cobertas pela pensão
Despesas extraordinárias: escola particular, médico especialista,
  atividade extracurricular, medicamento de uso contínuo
  → Precisam de aprovação prévia do outro genitor

Fluxo:
  → Um genitor registra a despesa + nota fiscal
  → Notifica o outro: "Matrícula do curso de natação: R$280. Metade sua: R$140"
  → Outro aprova ou recusa (com justificativa)
  → Se recusa sem justificativa válida: documentação para cobrança judicial
  → Saldo de quanto cada um deve/está devendo
```

**Diário da criança:**
```
Registro de momentos importantes:
  → Primeiro dente, apresentação escolar, consulta médica
  → Ambos os pais podem adicionar
  → Criança tem acesso quando crescer

Por que importa: em disputas de guarda, juízes avaliam qual genitor
está mais presente e engajado no desenvolvimento da criança.
O diário é prova de presença, não de ausência.
```

### Módulo 4 — Reconhecimento de Paternidade

**Situação:** criança sem pai registrado — muito comum no Brasil.
Mais de 5M de crianças sem o nome do pai na certidão.

```
Plataforma orienta:
  → Reconhecimento voluntário: processo simples via cartório
  → Recusa do pai: ação de investigação de paternidade
    (DNA pelo SUS é gratuito, mas processo é burocrático)

Automatiza:
  → Documentação para cartório (reconhecimento voluntário)
  → Petição inicial de investigação de paternidade
  → Conecta com advogado parceiro para casos contestados

Implicações automaticamente calculadas:
  → Direito a pensão alimentícia retroativa (desde o nascimento)
  → Inclusão no plano de saúde do pai
  → Herança
  → INSS: filho passa a ser dependente
```

**Filosofia:** o módulo de divórcio é o momento de aquisição (dor aguda).
O módulo de co-parentalidade é o produto de retenção (dor crônica).

```
AQUISIÇÃO                      RETENÇÃO
─────────────────────────────────────────────────────
Divórcio extrajudicial:        Co-parentalidade:
R$499 fixo (one-time)          R$39/mês por família

Referral judicial:             Pensão pro:
25% do honorário              R$59/mês (inclui execução automática)
(R$800-3.000 por caso)

Reconhecimento paternidade:
R$199 fixo
```

| Plano | O que inclui | Preço |
|-------|-------------|-------|
| **Free** | Triagem + calculadora de pensão | R$0 |
| **Divórcio** | Processo extrajudicial completo | R$499 único |
| **Família** | Co-parenting (calendário + comunicação + gastos) | R$39/mês |

**LTV por usuário:**
```
Divórcio: R$499 (one-time)
+ Co-parenting: R$39/mês × 12 anos (até filho completar 18) = R$5.616
+ Revisões de pensão: R$299 × 2-3 vezes = R$600-900
LTV total: R$6.700-7.000 por família
```

## O Que Torna Defensável

**1. O histórico é o produto**
Após 6 meses usando o app, o histórico de comunicação,
pagamentos e calendário é tão valioso que o usuário não consegue sair.
Churn naturalmente próximo de zero para usuários com co-parenting ativo.

**2. Efeito de rede negativo**
Se um dos pais usa, o outro é obrigado a usar.
Cada cliente adquirido traz um segundo usuário grátis.
CAC efetivo cai pela metade.

**3. Validação judicial**
Quando um juiz de GO ou DF recomendar o Concilia em uma sentença
(como OurFamilyWizard é recomendado por juízes nos EUA),
é um moat impossível de replicar.

**Estratégia para chegar lá:** parceria com 2-3 varas de família
em Goiânia e Brasília para validação. Oferecer gratuitamente para
famílias em processo judicial como projeto-piloto.

## Estrutura Jurídica

**O que o Concilia pode fazer sem advogado:**
- Triagem e orientação (informação jurídica, não aconselhamento)
- Geração de documentos (minuta que advogado parceiro revisa)
- Rastreamento de pagamentos (tecnologia pura)
- Comunicação auditável (tecnologia pura)
- Calendário de guarda (tecnologia pura)

**O que exige advogado parceiro:**
- Assinar qualquer peça jurídica
- Representar em audiência
- Protocolar execução de alimentos
- Casos litigiosos

**Rede de advogados parceiros em GO + DF:**
- 15-20 advogados especializados em direito de família
- Plataforma faz a triagem e a preparação
- Advogado faz a execução jurídica
- Split: advogado 70% / plataforma 30% dos honorários

## Go-to-Market

**Fase 1 — GO + DF (meses 1-6)**

Canal primário: **grupos de mães separadas**
Existem centenas de grupos de WhatsApp e Instagram de mães
que não recebem pensão, mães em processo de divórcio, grupos
de apoio a mulheres em situação de violência doméstica.
Esses grupos têm 200-2.000 membros cada, são muito ativos
e confiam em recomendações de outras membras.

Canal secundário: **CRAM e CRAS**
Centro de Referência de Atendimento à Mulher (CRAM) em Goiânia e Brasília.
Parceria para indicar o Concilia para mulheres em processo de separação.
É um canal com volume e com o perfil exato do usuário.

Canal terciário: **advogados de família como parceiros e distribuidores**
Advogado que usa a plataforma para seus clientes vende o produto
naturalmente. Ele cobra menos (preparação automatizada) e entrega mais
(histórico organizado, documentos prontos).

**Fase 2 — expansão nacional**

Após validar em GO + DF, replicar com foco em capitais
com alta taxa de divórcio: SP, RJ, MG.

## Protocolo de Violência Doméstica

Produto de direito de família não pode ignorar que muitas
separações envolvem violência. Protocolo específico:

```
Se usuária indica histórico de violência:
  → NÃO tenta mediar ou conciliar
  → Direciona imediatamente para:
    - Delegacia da Mulher mais próxima
    - CRAM (Centro de Referência de Atendimento à Mulher)
    - Defensoria Pública
    - Ligue 180 (Central de Atendimento à Mulher)
  → Orienta sobre Medida Protetiva (Lei Maria da Penha)
  → NUNCA comunica o endereço da usuária para o outro cônjuge via plataforma
  → Relatórios de localização: desativados para casos de violência
```

## Nome e Posicionamento

**Nome: Concilia**

Do verbo conciliar — mas não no sentido de "reconciliar o casal".
No sentido jurídico: chegar a um acordo, conciliar interesses,
mediar conflitos. É o que acontece em toda audiência de conciliação
familiar nos tribunais brasileiros.

Soa profissional, humano e resolve o que o produto faz.

Alternativas:
- **Acordo** — direto, mas pode soar frio
- **Laço** — evoca vínculos familiares que persistem após o divórcio
- **Nexo** — conexão/ligação entre as partes
- **Partilha** — mais focado em bens, menos em família

**Posicionamento:**
> *"Separar é difícil. Criar filho junto depois é mais difícil ainda.
> O Concilia organiza os dois."*

```

  → Imóvel Regular / Imóvel Certo para escritura e regularização

Pensão não paga = dívida?
  → Aravo não (é para dívidas de consumo) — permanece no Concilia

Ex-cônjuge quer abrir empresa após separação?
  → Validê para validar a ideia
  → MEI Automatizado para abrir e gerir

Criança do divórcio vai herdar?
  → Inventário e Herança (produto #1 do segundo lote)

INSS do cônjuge dependente?
  → Amparo para verificar direitos previdenciários após separação
```
